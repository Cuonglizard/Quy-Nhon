# Quy Nhơn

Thư viện ảnh cá nhân, xem thuận tiện trên điện thoại bằng GitHub Pages.

## Mở thư viện ảnh

Sau khi bật Pages cho repository, truy cập:

https://cuonglizard.github.io/Quy-Nhon/

## Bật GitHub Pages lần đầu

1. Mở repository tại https://github.com/Cuonglizard/Quy-Nhon
2. Chọn **Settings** > **Pages**.
3. Ở **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch **main**, thư mục **/ (root)** rồi bấm **Save**.
5. Chờ khoảng một phút, sau đó mở link Pages ở trên.

Repository cần để chế độ **Public** nếu muốn xem ảnh mà không đăng nhập GitHub.

## Cập nhật ảnh

Đặt ảnh mới vào thư mục album tương ứng, thêm tên file vào danh sách `photos` trong `index.html`, rồi commit và push lên branch `main`.
